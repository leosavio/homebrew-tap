# leosavio/homebrew-tap

Homebrew formulae for tools published by [@leosavio](https://github.com/leosavio).

```sh
brew install leosavio/tap/costgate
```

| Formula | Description |
|---|---|
| [`costgate`](Formula/costgate.rb) | Offline, fail-closed monthly AWS cost projection of terraform/tofu plans ([repo](https://github.com/leosavio/costgate)) |

Formulae install the signed release binaries; each `url` is pinned by `sha256` from the
release `checksums.txt`. `Formula/costgate.rb` is generated by the release workflow of
`leosavio/costgate` (`scripts/homebrew-formula.sh`); do not edit it by hand.
