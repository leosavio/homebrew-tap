# leosavio/homebrew-tap

Homebrew formulae for tools published by [@leosavio](https://github.com/leosavio).

```sh
brew install leosavio/tap/costgate
brew install leosavio/tap/kubestrata
```

| Formula | Description |
|---|---|
| [`costgate`](Formula/costgate.rb) | Offline, fail-closed monthly AWS cost projection of terraform/tofu plans ([repo](https://github.com/leosavio/costgate)) |
| [`kubestrata`](Formula/kubestrata.rb) | Read-only, time-layered inventory of Kubernetes clusters for migration planning ([repo](https://github.com/kubestrata/kubestrata)) |

Formulae install the signed release binaries; each `url` is pinned by `sha256` from the
release `checksums.txt`. Each formula is generated by the release workflow of its repository
(`scripts/homebrew-formula.sh` in `leosavio/costgate` and `kubestrata/kubestrata`); do not edit
them by hand.
